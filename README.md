# Howl-Player
HTML video player for Howl app:
https://github.com/Amethyst-Sysadmin/Howl

It allows you to control Howl app, load .hwl or .funscript files directly from PC and sync them to video. You can also queue video+script pairs or separate files.

Added MP3 to HWL conversion and delay sliders

Added frequency slider. Frequency values are stored locally and sent to Howl app on connect. Improved reconnect logic

Added script visualizer overlay and hotkeys

Added heatmap. More hotkeys

Added hotkeys remap. You can now connect to 2 separate Howl apps.
Player was reworked for new websocket API that was added in Howl 2.0. Earlier versions ARE NOT SUPPORTED.
